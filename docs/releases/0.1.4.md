A fix for downloading MangoMemory by hand.

## Fixed

- The download from GitHub could show "MangoMemory.app Not Opened" after you unzipped it with some tools, even though the app is signed and notarized. The zip no longer contains the hidden files that caused it, and every release is now checked by unzipping it the plain way before it ships.

Nothing else changed. If MangoMemory updated itself before, it keeps working the same way.
